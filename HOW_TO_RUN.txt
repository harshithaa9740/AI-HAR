AURAVISION - AI Human Activity Recognition (ISRO / SIH Edition)
React + TypeScript Frontend + FastAPI Backend (Offline LAN)
============================================================

HOW TO RUN:

👉 1. One-Click Launch (Recommended):
   Double-click "start-auravision.bat"
   - Automatically starts the FastAPI Backend on http://0.0.0.0:8000
   - Automatically starts the React Frontend on http://0.0.0.0:3000
   - Opens http://localhost:3000 in your browser!

👉 2. Running on Local Wi-Fi / LAN with 2 Laptops:
   - Laptop 1 (Backend Server):
     1. Connect to Wi-Fi / Hotspot.
     2. Run "ipconfig" in Command Prompt to find its IPv4 address (e.g., 192.168.1.25).
     3. Start backend: double-click "start-auravision.bat"
   - Laptop 2 (Client / Judges):
     1. Connect to the same Wi-Fi / Hotspot.
     2. Open browser: http://<BACKEND_IP>:3000 (e.g. http://192.168.1.25:3000)
     3. On the "Connect to AURAVISION Backend" dialog, enter the IP (192.168.1.25) and port 8000.
     4. Click "Test Connection (GET /api/health)" -> Click "Save & Connect".

ADDRESSES & PORTS:
- React Frontend:          http://localhost:3000
- FastAPI Backend:         http://localhost:8000/api/health
- WebSocket Event Stream:  ws://localhost:8000/ws/events
- Live MJPEG Camera Feed:  http://localhost:8000/api/video/feed
- Legacy Static UI:        http://localhost:8080
